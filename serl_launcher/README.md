# CIRL Launcher (serl_launcher)

This package contains the reinforcement learning agent, network architectures, and training launcher code for CIRL.

- Dependencies: `jax`, `agentlace`

Code and scripts are built on top of [jaxrl_m](https://github.com/dibyaghosh/jaxrl_m) or [jaxrl_m private](https://github.com/rail-berkeley/jaxrl_minimal).
